# Markdowneditor

En fristående Markdowneditor med svensk meny, förhandsgranskning och stöd för Mermaid. Du kan öppna, skapa och spara lokala Markdownfiler.

## Använd editorn

[Ladda ned ZIP-filen](https://github.com/davidsenseit/markdowneditor/archive/refs/heads/main.zip), packa upp den och öppna `markdowneditor.html` i webbläsaren. Editorn fungerar offline och kan kopieras mellan projekt som en enda fil.

I förhandsgranskningen kan du välja typsnitt och textstorlek. För att skapa en PDF klickar du på **Exportera till PDF** och väljer **Spara som PDF** i webbläsarens utskriftsdialog. PDF-filen använder A4 och samma typografi som förhandsgranskningen.

Under **Hjälp** finns en guide och kopierbara exempel för Markdown och Mermaid.
